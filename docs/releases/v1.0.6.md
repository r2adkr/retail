> retail is a self-hosted mesh VPN. Your devices reach each other directly over WireGuard, from any network, through a server you run yourself: on one of your own devices or on a small VPS.

**Direct connections on Windows PCs that also have Tailscale, and usage totals that last.** A Windows device with Tailscale installed could lose its WireGuard port to it and go through the relay everywhere. The Info tab now also counts traffic across connections and restarts.

## What's changed

### Windows: direct connections next to Tailscale

- Tailscale uses the same UDP port as retail (41641). On Windows the two could share it without an error, and Tailscale then received retail's packets: the device never learned its public address and every peer went through the relay, with "UDP is blocked on this network" as the reason.
- retaild now holds its port alone. If another program already has it, retaild uses another port, as it does on Linux and macOS.
- Games through an exit node were hit hardest: everything went over the relay's TCP connection, where each lost packet held the rest back for a second or more.

### Restarts no longer look like retaild stopped

- When part of the tunnel failed and retail restarted its connection, the tray could say retaild was not running (or show nothing) until the restart finished. retaild now keeps answering during a restart.
- If that part fails again, the log says which part and why, where before it said nothing.

### Usage totals

- Settings → **Info** shows **Total sent** and **Total received** since a date, next to this connection's traffic. Each device's traffic is its total too.
- It also shows the time connected: in total, and for this connection. The tray's **This device** card shows how long this connection has lasted.
- A device's row no longer shows how long ago its last handshake was. WireGuard renews keys every 2 minutes, so that time kept starting over and looked like reconnects. It shows only when a device has been quiet for over 3 minutes.
- The totals survive reconnecting, restarts and updates (kept in `usage.json` in the state folder).
- `retail status` prints the totals.

> [!NOTE]
> A download through an exit node (a speed test, a game patch) fills the exit node's upload and raises the ping of everything else going through it. Pause downloads while playing.

## Upgrading

Installed devices update themselves within a few hours (or at once: tray app → ⚙ → Settings → **Check now**). Running the new installer over an installed retail updates it as well. Server data, keys and settings stay.

Installing for the first time: see the [1.0.0 release notes](https://github.com/r2adkr/retail/releases/tag/v1.0.0) or the [README](https://github.com/r2adkr/retail#readme).

> [!NOTE]
> The installers are not code-signed yet. Windows SmartScreen asks to confirm: **More info → Run anyway**. macOS Gatekeeper wants **right-click → Open** the first time.

## Verify your download

`SHA256SUMS` lists every installer's checksum (also below).

```sh
grep retail-linux-x86_64.deb SHA256SUMS | sha256sum -c     # Linux: prints OK
grep retail-macos.dmg SHA256SUMS | shasum -a 256 -c          # macOS: prints OK
```

```powershell
(Get-FileHash .\retail-windows-x86_64.exe).Hash           # Windows: compare with SHA256SUMS
```
