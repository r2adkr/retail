> retail is a self-hosted mesh VPN. Your devices reach each other directly over WireGuard, from any network, through a server you run yourself: on one of your own devices or on a small VPS.

**macOS: drag retail onto Applications, and direct connections next to Tailscale.** The disk image now opens with an Applications folder next to retail, as other Mac apps do.

## What's changed

### macOS: drag onto Applications

- Opening `retail-macos.dmg` shows retail and a link to Applications. Drag retail onto it and open it from Applications; the same short setup runs as before. Opening it right in the disk image still works.
- After the setup, Applications holds retail's small app that opens the menu bar app's window.

### macOS: direct connections next to Tailscale

- As on Windows before 1.0.6, macOS let retaild share its UDP port with a program that already held it for IPv4 (Tailscale on 41641), and that program then received retail's packets. retaild now finds such a program first and uses another port.

## Upgrading

Installed devices update themselves within a few hours (or at once: tray app → ⚙ → Settings → **Check now**). Running the new installer over an installed retail updates it as well. Server data, keys and settings stay.

Installing for the first time: see the [1.0.0 release notes](https://github.com/r2adkr/retail/releases/tag/v1.0.0) or the [README](https://github.com/r2adkr/retail#readme).

> [!NOTE]
> The installers are not code-signed yet. Windows SmartScreen asks to confirm: **More info → Run anyway**. macOS Gatekeeper wants **right-click → Open** the first time.

## Verify your download

`SHA256SUMS` lists every installer's checksum (also below).

```sh
grep retail-linux-x86_64.deb SHA256SUMS | sha256sum -c     # Linux: prints OK
grep retail-macos.dmg SHA256SUMS | shasum -a 256 -c          # macOS: prints OK
```

```powershell
(Get-FileHash .\retail-windows-x86_64.exe).Hash           # Windows: compare with SHA256SUMS
```
